## 🎯 Key Features

### 5-Role Hierarchy System

- **Admin** - God mode (full control)
- **Manager Area** - Regional management (5% commission)
- **SPV** - Team supervision (10% commission)
- **Partner** - Service providers (30-55% commission)
- **Client** - Buyers

### Commission Structure

- **Partners:** 30-55% based on tier (TIER 1-4)
- **SPV:** 10% from downline + ARPU bonuses
- **Manager:** 5% from area + ARPU bonuses
- **ARPU Bonuses:** Up to Rp 15M/month

### Pricing Model

**Option 1: Beli Putus** (One-time purchase)
- Landing page: Rp 350,000
- Multi-page: Rp 350,000 × pages

**Option 2: Sewa Bulanan** (Monthly subscription)
- Landing page: Rp 150,000/month
- Multi-page: Rp 150,000 × pages
- No setup fee, no minimum contract
